# 双11活动页面埋点位置清单

更新日期：2026-10-27。配套文档：[双11活动核心埋点需求](双11活动核心埋点需求.md)。

本清单按现有 Demo 的页面结构和实际按钮文案定位。下面列的是“埋在哪里”；同一种统计行为在多个位置复用，通过来源区分，不需要每个按钮建立一套指标。

**曝光**：该区域实际出现在用户屏幕内。**点击**：用户点中可用控件。**成功**：对应业务已完成，不能用点击或动画结束替代。

## 首页与专家鉴别页

| 具体位置 | 需要埋什么 | 要保留的区分 |
|---|---|---|
| 首页顶部“专家鉴别”Tab，右上角带“限免”角标 | Tab曝光、点击；专家鉴别页实际出现时记录到达 | 来源为首页顶部Tab；点击角标与Tab只算同一次点击 |
| 首页轮播下方的中奖滚动播报，例如“某某抽中了 YSL气垫” | 播报曝光、点击；到达专家页活动区域 | 来源为中奖播报；循环展示和复制滚动内容不重复计曝光，播报不算真实中奖 |
| 首页左上角菜单展开后的“抽奖中心”入口 | 入口曝光、点击；活动选择页到达 | 来源为首页菜单；菜单未展开不算入口曝光 |
| 专家鉴别页上半屏的“立即鉴别”按钮 | 按钮及服务利益点曝光、去专鉴点击 | 来源为专家页上半屏；后续提交订单保留该来源 |
| 专家鉴别页下半屏，“专鉴有礼·替你的双11战利品兜底”下面的扭蛋机图案 | 机台入口曝光、点击；“双11扭蛋”弹窗实际打开 | 来源为专家页机台图案 |
| 悬浮在上述扭蛋机上的“去扭蛋”按钮 | 按钮曝光、点击；“双11扭蛋”弹窗实际打开 | 来源为专家页去扭蛋按钮；与点击机台图案分开 |
| 扭蛋机右上角的“王者榜”入口 | 入口曝光、点击；榜单弹窗实际打开 | 来源为专家页王者榜 |

机台图案与“去扭蛋”按钮可能互相包含，点击同一个位置不能同时记成两个入口点击。

## 首次赠券弹窗

| 具体位置 | 需要埋什么 | 要保留的区分 |
|---|---|---|
| 首次进入时出现的“双11专鉴有礼”弹窗，包含“免费专鉴，攒券扭好礼” | 首赠介绍曝光 | 关联原首次引导赠券；弹窗重绘不重复统计 |
| 弹窗下方“免费扭一次”按钮 | 抽奖发起；实际扣券并确定结果后记录抽奖成功 | 来源为首次赠券弹窗；使用的是否为首次引导券，以券记录判断 |
| 每日赠券真正到账的位置，无须用户点按钮 | 抽奖券到账 | 首次引导赠券与后续每日赠券分开；未弹窗也可能已到账 |

“稍后再用”和关闭按钮本轮不单独埋点。用户之后从其他入口使用原首次赠券，仍属于首赠使用。

## 专家页打开的“双11扭蛋”弹窗

| 具体位置 | 需要埋什么 | 要保留的区分 |
|---|---|---|
| 点击专家页扭蛋机或“去扭蛋”后出现的“双11扭蛋”弹窗主体 | 活动承接到达 | 带上原来的机台/去扭蛋来源 |
| 扭蛋机下方左侧“免费扭一次”或“扭一次”按钮 | 抽奖发起；实际扣券并确定结果后记录成功 | 来源为专家页扭蛋弹窗；普通/高级、单抽、实际消耗券来源 |
| 右侧“五次一起扭”按钮 | 抽奖发起；实际扣券并确定结果后记录成功 | 来源为专家页扭蛋弹窗；普通/高级、五连 |
| 没有任何可用抽奖券时，“再鉴N单，得1张…”及“去专鉴赢抽奖券”区域 | 无券引导曝光、去专鉴点击 | 当时普通券和高级券余额均为0；距下一奖励的单数 |
| 有券时，弹窗底部“去专鉴”按钮 | 专鉴引导曝光、去专鉴点击 | 来源为有券扭蛋弹窗，不能混入无券引导 |
| 弹窗上方“王者榜”入口 | 点击及榜单到达 | 来源为扭蛋弹窗 |

“免费扭一次”的按钮文案不代表首次赠券；后续每日券也会显示该文案。普通券、高级券的切换本轮不单独统计，实际发起抽奖时记录选中的券种即可。

## AI结果后的专鉴卡与专鉴提交页

| 具体位置 | 需要埋什么 | 要保留的区分 |
|---|---|---|
| AI报告下方“专家一对一鉴别／限时免费”卡片 | 卡片实际曝光 | 来源为AI结果卡；关联当前AI报告、品类 |
| 卡片右下方“去专鉴”按钮 | 去专鉴点击 | 后续提交订单保留AI结果卡来源；不按专家首页入口计算 |
| 专鉴上传点位页底部“提交专家评估”按钮对应的成功结果 | 专鉴提交成功 | 实际创建订单成功才记录；关联发起来源、品类、活动资格、累计单数 |
| 提交后达到普通券或高级券节点，券真正到账 | 抽奖券到账 | 关联本次订单；普通/高级、累计奖励来源、张数及有效期 |

“提交专家评估”的按钮点击不等于订单提交成功；失败、连点或重试不能多记订单。AI卡片“查看详情”、品类列表的“活动”角标和每个上传点位，本轮不单独埋点。

| 普通结果下方“去专鉴”按钮 | 引导曝光、去专鉴点击，关联成功提交 | 来源分别标识实物结果、鉴别券结果、未中奖结果 |

| 具体位置 | 需要埋什么 | 要保留的区分 |

## 我的奖品

| 具体位置 | 需要埋什么 | 要保留的区分 |
|---|---|---|
| 顶部“我的奖品”Tab，或从扭蛋弹窗、结果弹窗进入后的页面 | 我的奖品页到达 | 进入来源；统计后续奖品行为时只取双11奖品 |
| 实物奖品卡片“填写收货信息／修改收货信息”打开的弹窗中，“保存收货信息”成功后 | 实物领奖资料完成 | 按对应实物奖品去重；再次修改地址不新增一份已领奖品 |
| 紫色“专家线上鉴别券”券面上的“去使用”按钮 | 使用入口点击，复用去专鉴点击 | 来源为我的奖品鉴别券；关联这张双11奖品券 |
| 这张专家线上鉴别券真正被消费、核销的位置 | 鉴别券核销成功 | 取实际核销结果；不在点击“去使用”时记核销 |

当前 Demo 中“去使用”是进入专鉴流程，不具备真实核销凭据。正式埋点必须接实际核销结果；鉴别券实际到账量也取奖品记录，不能用开奖结果展示次数代替。

## 本次位置清单对应的统计类型

复用核心方案的12种统计类型：入口或引导展示、入口点击、承接到达、去专鉴点击、专鉴提交成功、抽奖券到账、活动引导弹窗展示、**抽奖发起**、抽奖成功、结果展示、榜单展示、奖品领取或使用完成。

本次补充“抽奖发起”，对应所有真实可用的抽奖按钮，便于区分“点了但没完成”和“已经抽奖成功”。一次五连只记一次发起；同次请求重试或连点不重复记。需关联这次操作的最终成功、失败或处理中状态；暂未收到结果不能直接判失败。抽奖完成率＝完成扣券并确定结果的操作次数 ÷ 已有明确最终结果的有效发起次数 × 100%；仍在处理的操作单列。
