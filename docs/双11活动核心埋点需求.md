# 双11活动核心埋点需求

## 观测目标

主要回答三个问题：活动吸引了多少用户提交专鉴；赠券和抽奖能否推动用户继续专鉴；哪些入口和激励方式值得在下次活动保留。

核心结果看：**参与专鉴人数、专鉴订单数、重复专鉴率**。其他数据用于解释这三个结果。

## 需要观测的业务链路

| 链路 | 需要看清楚什么 |
|---|---|
| 活动入口 → 去专鉴 → 提交成功 | 哪个入口吸引用户、哪个入口实际带来专鉴。区分首页播报、专家页、AI结果卡、抽奖中心等来源 |
| 首赠券到账 → 使用赠券抽奖 → 看到结果引导 → 去专鉴 → 提交成功 | 免费体验能否带来专鉴；用户选择稍后使用后，从抽奖中心使用原赠券也要关联回来 |
| 专鉴提交 → 进度弹窗 → 去专鉴 → 再次提交 | 累计进度和发券奖励能否促成下一单；区分未获券、普通券、高级券三个节点 |
| 王者榜展示 → 去专鉴 → 提交成功 | 榜单是否带来专鉴；区分鉴真榜、避雷榜，以及本人是否已上榜 |

奖品承接只补充观察：**实物中奖后是否提交收货信息；中奖鉴别券是否实际使用**。

## 核心统计点

仅保留以下 **10 个核心统计点**；同一行为在不同页面复用，只区分来源。

| 统计点 | 什么时候记录 | 必要区分 |
|---|---|---|
| 活动入口展示 | 用户实际看到活动入口时 | 入口位置；AI结果卡单独区分 |
| 活动入口点击 | 用户点击入口，进入对应活动页面或弹窗时 | 点击来源、进入哪里 |
| 去专鉴点击 | 用户点击立即鉴别、去专鉴或去专鉴赢抽奖券时 | 来源：专家页、AI结果卡、首抽结果、进度弹窗、无券引导、榜单 |
| 专鉴提交成功 | 订单提交成功时 | 品类、来源、是否参与本次活动、本人活动累计单数 |
| 抽奖券到账 | 每日赠券或累计奖励实际到账时 | 普通/高级、每日/累计、是否首次引导赠券、到账张数 |
| 活动弹窗展示 | 首赠介绍或每单进度弹窗实际展示时 | 首赠/进度；当前单数；未获券/普通券/高级券节点 |
| 抽奖成功 | 扣券并确定抽奖结果后 | 使用券种和来源、单抽/五连、消耗张数、实物/鉴别券/未中奖数量、是否消耗首次引导券 |
| 抽奖结果展示 | 用户实际看到本次抽奖结果时 | 结果类型、是否首次引导、对应抽奖批次 |
| 王者榜展示 | 用户实际看到某个榜单时 | 鉴真/避雷、本人排名或未上榜状态 |
| 奖品领取或使用完成 | 实物收货信息保存成功，或中奖鉴别券实际核销时 | 两种行为分别统计；奖品类型、数量、所属活动 |

“去专鉴点击”统一承接各处引导，无需给每个按钮另建统计点。未中奖安慰动画、跳过动画、规则查看、券列表筛选等细节本轮不单独统计。

## 核心指标口径

| 指标 | 统计方式 |
|---|---|
| 参与专鉴人数、订单数 | 活动期间符合活动品类的提交成功用户数、订单数；分别按用户、订单去重 |
| 重复专鉴率 | 活动期间提交至少2单的用户数 ÷ 至少提交1单的用户数；同时看人均提交单数 |
| 入口转化 | 点击入口人数 ÷ 看到入口人数；通过该入口链路提交成功人数 ÷ 看到入口人数 |
| 首赠使用及转专鉴 | 使用首次赠券人数 ÷ 首赠到账人数；看到首抽结果引导后，经该引导提交专鉴人数 ÷ 看到该引导人数 |
| 进度引导转化 | 经进度弹窗引导再次提交的原订单数 ÷ 展示进度弹窗的原订单数；按未获券/普通券/高级券节点拆分 |
| 榜单转化 | 经榜单去专鉴并提交成功人数 ÷ 看到榜单人数；两榜分别统计 |
| 抽奖券使用率 | 成功消耗张数 ÷ 到账张数；按每日券、累计普通券、累计高级券拆分，同时展示未用过期张数 |
| 奖品承接 | 提交收货信息的实物奖品数 ÷ 实物中奖数；已核销鉴别券张数 ÷ 实际到账鉴别券张数 |

转化统计必须跟随同一批用户或订单向后追踪，不能把当天全部提交量直接除以当天曝光量。活动进行中展示截至当前数据，最终按活动完整周期复盘；鉴别券使用持续观察至其有效期结束。较晚参与者的重复专鉴机会更少，复盘时按首次参与日期拆分比较。

## 复盘如何使用这些数据

| 看到的数据表现 | 复盘重点与后续方向 |
|---|---|
| 入口曝光多、点击少 | 检查入口文案、利益点与位置，下次优化入口吸引力 |
| 点击去专鉴多、提交少 | 检查选品和传图流程的流失，结合用户反馈定位原因 |
| 首赠使用多、后续专鉴少 | 检查用户是否理解“专鉴继续得券”，优化抽后引导 |
| 进度弹窗展示多、再次提交少 | 对比三个节点的继续专鉴表现，评估奖励吸引力及里程碑设置 |
| 券到账多、使用少或过期多 | 检查抽奖入口和使用动机，评估赠券节奏与有效期 |
| 榜单访问多、专鉴转化少 | 评估榜单奖励和追赶目标是否足够明确，决定是否继续保留 |

活动结束后给出：**最有效入口、首赠是否带来专鉴、哪类节点的继续专鉴表现最好、券的实际使用情况，以及下期优先调整的环节**。这些数据说明关联转化；若要判断活动净增量，需要另设对照。

## 必须统一的业务规则

- 活动品类按8类预留，以实际上线配置判断。订单提交成功即累计，不等待鉴定结论；其他免费品类不混入活动订单。
- 每单活动订单都观察进度弹窗，不只观察获券节点。风控关闭弹窗的订单不计入应展示范围，但累计、发券和抽奖数据仍保留。
- 首次固定未中奖只关联首次引导赠券；普通每日券与它分开。五连算1个抽奖批次、5次抽取，不能按1次计算中奖比例。
- 同一订单只记一次；同一笔直接转化只归一个去专鉴来源。导航入口的导流贡献与直接来源不相加计算总订单。
- 券按张数统计；中奖鉴别券与抽奖券分开。实物提交收货信息不代表已发货，点击鉴别券“去使用”不代表已核销。
- 双11与卡牌活动分开，历史记录与模拟数据不计入本次真实活动表现。
